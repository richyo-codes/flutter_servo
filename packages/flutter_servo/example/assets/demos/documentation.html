This page is bundled with the app. It needs no network connection and exercises anchors, selectable code, expandable help, and long-form scrolling.

Getting started

Use a URL surface for hosted content, or an HTML surface for content generated by your application. Keep navigation controls in Flutter and render the document inside Servo.

FlutterServoSurface.html(
  content: '<h1>Hello from Servo</h1>',
)

Resize the window or select the phone viewport to check text wrapping. The page should redraw without requiring a mouse hover.

Input checklist

  1. Select and copy a paragraph.
  2. Tab between links and form controls.
  3. Use the contents links, then scroll back.
  4. Type accented characters in the field below.

Native focus and web focus are separate. Ctrl+L should focus the Flutter address bar, while clicking this input should send text to the web document.

Troubleshooting

The page stays blank

Check the native renderer log and load error before assuming the document loaded successfully. Try a bundled demo to eliminate network errors.

Video does not play

Rendering HTML does not imply codec or media-backend support. Use the video diagnostic demo and inspect its error and capability output.
